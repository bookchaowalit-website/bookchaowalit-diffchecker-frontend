# Diff Checker

Side-by-side line diff for plain text.

## Features
- Line-level LCS-style diff
- Added / removed / unchanged markers
- Stats summary

## Limitations
- Character/word diff modes not included
- Large files may be slow in pure JS

## Run
```bash
npm install
npm run dev
```

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Fully client-side (no API keys)

## Honesty notes
- Portfolio developer utility showcase
- Not a multi-tenant SaaS product
