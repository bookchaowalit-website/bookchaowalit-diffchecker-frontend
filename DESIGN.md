# Diff / Desk — Design direction

## Direction

Assigned operate-mode direction translated into a forensic proof desk: two
versions are evidence sheets and the report marks what moved, stayed, or was
introduced.

## Visual system

- Cool paper, ink, blue evidence labels, green additions, and red removals.
- Sora carries the report voice; Roboto Mono carries source text, line numbers,
  and the ledger.
- Ruled evidence sheets and a line ledger replace generic dashboard cards.

## Interaction contract

The comparison remains live while typing; Run comparison, Swap evidence, Clear
desk, and the line-level stats remain available. Signs and labels accompany
color so changes are never color-only.

## Responsive behavior

The evidence columns stack on mobile, while the marked ledger keeps line number,
change sign, and source text aligned in a scrollable report.
